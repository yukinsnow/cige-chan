词格酱 · 中文歌词写作台

按作曲给出的词格摆好空格子，你只管往里填字。

导入格式

纯文本 .txt，段落标记用中括号或直接写 Verse/Chorus，X 表示一个字，空格表示停顿分组，空行也可分段：

[Verse 1]
XXXX XXX
XXX XXXX
XX XXXXX

[Chorus]
XXXXX XXX
XXXX XXXX

也支持这些写法：数字词格 4+3 或 7；○ ● □ × 等占位符；直接粘贴一段现成歌词，会自动反推词格并填入文字。

快捷键

  • Enter 在下方新建一句（沿用当前词格）
  • Tab / Shift+Tab 下一句 / 上一句
  • ↑ ↓ 跨句移动，保持光标列位置
  • Ctrl/⌘ + ] / [ 在光标所在的分句里加 / 减一格
  • Ctrl/⌘ + \ 在光标处断开分句；光标已在分句边界时则合并相邻两个分句
  • Alt + ↑/↓ 上移 / 下移整句
  • 空句上按 Backspace 删除该句
  • 点左侧灰色数字（如 2/2/3）可直接改本句词格，输入 2 2 3、2/2/3 或 XX XX XXX 均可

背景

点顶部的「背景」可以换成自己的图片或纯色，也可以直接把图片拖进窗口。

  • 底色：夜间 / 稿纸两套，决定文字和格子的颜色。
  • 图片：会自动缩到合适尺寸再记住，不会拖慢程序。图片背景下可以调「蒙版浓度」和「模糊」两个滑块，把字压得清楚一些。
  • 纯色：选浅色会自动配深色字，选深色自动配浅色字。

背景只跟着这台电脑走，不会写进工程文件，发给作曲方的 json 里不会带上你的背景图。

光标与留空

点哪个格子，字就写在哪个格子——包括还没写到的空格子。比如你先想好了句尾那几个字，可以直接点到最后几格写下来，前面的格子留着慢慢填。

留空的格子在内部记作空格，不计入字数（右侧的 3/7 只数真正写了的字），导出时句尾多余的空格会自动去掉。句子中间敲空格也是同样的意思：跳过这一格。

分句（句内停顿）

词格中的空格代表一个停顿，例如 2/2/3 就是三个分句。光标落在哪个分句，下方就会出现一条橙线，此时 ＋ − 只作用于这个分句：把光标点进中间的 2，按 ＋ 得到 2/3/3，按 − 得到 2/1/3；分句只剩 1 格时再按 − 会整段去掉，变成 2/3。

备选版本与备注

光标落进某一句，这句下面就会展开一条工具栏。

  • ＋ 存为备选：把这句现在的写法存进版本清单，然后你可以继续改写。同一句想到几种写法就存几种。
  • 点带编号的小方块即可在各版本间来回切换，高亮的那个是当前生效的版本，小 × 删掉不要的。
  • 写了新东西还没点存时，前面会多出一个「未存」方块；这时候去点别的版本，工具会先自动把这份新写法存住再切换，不会丢稿。
  • 右边的备注输入框写给自己看的提示，比如「这句想押 ang 韵」「等作曲确认」。备注不占格子，也不计入字数。
  • 有备选或备注的句子，工具栏会一直显示；其余的只在光标进入时出现。

点「导出歌词」时可以勾选是否把全部备选（同句用 / 分隔）和备注（写在句末的 （） 里）一并写进 txt，勾选状态会被记住。「保存工程」导出的 json 始终包含全部备选和备注。
