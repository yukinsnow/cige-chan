词格

先有格子，后有词

写中文歌词的时候，作曲经常会先给一个「词格」——每句几个字、哪里停顿分组。比如 2/2/3 就是「两个字、两个字、三个字」这样一句。旋律定了，字数就定了，多一个少一个都唱不进去。

词格酱把这种格子原样摆出来，你对着格子逐字填词。右边实时数着填了几格、完成度多少，句尾溢出会单独标红。

作曲给的XXXX XXX
摆成格子4/3
填完春风吹过山与海
填词

格子是钉死的

每个字待在自己那一格，不会因为别处的增删整体挪位——这是这个工具跟普通文本框最大的区别。

覆盖

打字覆盖当前格

在中间补字不会把后面的字往后顶。先想好的句尾原地不动，不会被推出词格丢掉。

留白

删字原地留空

删掉中间某个字，那一格变成空格子，后面的字不跟着往前挪，始终跟旋律对得上。

跳填

可以先落句尾

点哪个格子就写在哪个格子，包括还没写到的空格。先把押韵的句尾定下来，前面慢慢填。

分句

句内停顿分组

2/2/3 就是三个分句。光标落在哪个分句，加减格就只作用于那一个，不动别的。

改稿

同一句，存下每一种写法

一句想到几种写法就存几种，点小方块随时切换对比。写了新东西还没存就去点别的版本，工具会先自动把这份新写法保住再切换——不会丢稿。

每句还能加一条备注，写给自己看：「这句想押 ang 韵」「等作曲确认」。备注不占格子，也不计入字数。导出歌词时可以勾选要不要把全部备选和备注一并写进 TXT。

进出

导入导出

导入认纯文本 .txt：X 表示一个字、空格表示停顿分组，也支持 4+3 这样的数字词格和 ○ ● □ × 占位符。直接粘贴一段现成歌词，会自动反推出词格并填好字。

导出时分句之间会留出空格，所以导出的歌词能被原样再导入回来。工程文件是 .cige.json，始终包含全部备选和备注。

实验功能

MIDI 生成词格

按旋律的音符数量自动生成词格，用三个 keyswitch 当分段标记：C0 分句、C#0 换句、D0 换段。

带校验

导出带歌词 MIDI

导出前逐句核对词格跟 MIDI 对不对得上，对不上会精确报出是第几段第几句并直接拦住，绝不导出错位的歌词。Synthesizer V 等支持 MIDI 歌词的软件能直接读。

假名

日语和韩语

打日语歌词时，きゃ しゅ ちょ 这类拗音会自动跟前一个假名拼成一格，显示为主字右下角的小字——这样数格子才对得上日语的音拍数，而不是字符数。促音 っ／ッ 不算在内，仍然独立占一格，因为它数拍时本来就该自己算一整拍。

韩语谚文（如 한）本身就是一个完整的 Unicode 字符，天然一格一个音节，直接填字就行，不需要额外设置。

界面语言支持中文 / 繁體中文 / 日本語 / 한국어，帮助面板等长文说明也会跟着换。

快捷键

手不用离开键盘

按键作用
Enter / Tab跳到下一句（不会新建句子）
↑ ↓跨句移动，保持光标的列位置
Ctrl/⌘ + ] [在光标所在的分句里加 / 减一格
Ctrl/⌘ + \在光标处断开分句；已在边界则合并相邻两个
Alt + ↑ ↓上移 / 下移整句
Alt + ← →把整句的字左移 / 右移一格，词格不动
Backspace在空句上按，删掉该句

点左侧灰色的词格数字（如 2/2/3）可以直接改本句词格，输入 2 2 3、2/2/3 或 XX XX XXX 都认。

装哪

四个平台，一份代码

网页版

打开 lyrics.response.run 直接用，电脑和手机浏览器都支持，不用装任何东西。

Windows / macOS / Linux

Releases 页面下载。没做付费签名，首次打开系统会拦一下：Windows 点「仍要运行」，macOS 右键「打开」，只需一次。

Android

下载 .apk，安装时允许一下「未知来源」即可。

iPhone / iPad

暂时没有现成安装包，建议直接用网页版，体验跟安装版基本一样。

歌词只存在你自己的设备上。内容保存在浏览器或应用的本地存储里，不会传到云端，也不会经过任何服务器。换设备、换浏览器、清本地数据之前，记得先导出一份工程文件备份，不然找不回来。
