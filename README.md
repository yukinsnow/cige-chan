名字是「词格」+「酱」——后者取日语 ちゃん 的亲昵后缀。

## 这是做什么用的

写中文歌词的时候，作曲经常会先给一个"词格"——每句几个字、哪里停顿分组，
比如 `2/2/3` 就是"两个字、两个字、三个字"这样一句。词格酱就是把这种格子
摆出来，让你对着格子逐字填词，输入法直接连打，不用自己数字数、防止超格或者漏格。

## 功能

- 按词格摆格子逐字填词，点哪个格子就写在哪个格子
- **格子是钉死的**：打字覆盖当前格，不会把后面的字往后顶；删字原地留成空格，后面的字也不会往前挪。先写好的句尾始终待在自己的格子里，不会被推出词格丢掉
- 可以先落句尾几个字、前面留空慢慢填
- 句内停顿分组（如 `2/2/3`），加减格只作用于光标所在的分句
- 整句写偏了可以用 `Alt + ←/→` 左右挪一格，词格不动；会把字挤出词格时会拦住
- 每句可以存多个备选写法，随时切换对比，切换前自动保住没保存的版本
- 每句可以加备注，不占格子
- 自定义背景：图片 / 纯色 / 两套底色，蒙版与模糊都能调
- 支持导入 txt 词格、或者拿现成歌词反推出词格；导出歌词（分句之间会留出空格，所以导出的歌词能被原样再导入回来；可以选是否带上全部备选写法与备注）、导出词格、导出工程文件
- **（实验）日语拗音**：打日语歌词时，`きゃ` `しゅ` `ちょ` 这类拗音会自动跟前一个假名拼成一格，显示为主字右下角的小字，不单占格子，数格子时按音拍算而不是按字符数；促音 `っ／ッ` 不算在内，仍然独立占一格
- **韩语兼容**：谚文（如 `한`）本身就是一个完整的 Unicode 字符，天然一格一个音节，不需要像日语拗音那样额外处理，直接填字就行
- **（实验）MIDI 导入/导出**：按旋律的音符数量自动生成词格，用三个 keyswitch（C0 分句／C#0 换句／D0 换段）当分段标记。导入一份没放 keyswitch 的 MIDI 时会先提示——所有音符会挤进一句，导入后得自己动手分句分段——确认了才导。配套两种导出：去掉 keyswitch 的纯净 MIDI，以及带逐句校验的歌词版 MIDI（词格跟音符数量对不上会直接拦住，不会导出错位的歌词；歌词版能被 Synthesizer V 等支持 MIDI 歌词的软件读取）
- **界面语言**：中文 / 繁體中文 / 日本語 / 한국어，右上角下拉切换，帮助面板等长文本说明也会跟着换

## 怎么用

**网页版**：打开 [lyrics.response.run](https://lyrics.response.run/) 直接用，电脑、手机浏览器都支持，不用装任何东西。

**电脑安装版（Windows / macOS / Linux）**：去 [Releases 页面](../../releases) 下载对应平台的安装包。
这些包没有做付费签名，首次打开时系统会拦一下，这是正常现象：

- **Windows**：点「更多信息」→「仍要运行」
- **macOS**：右键点应用 →「打开」→ 再点弹窗里的「打开」，只需做一次
- **Linux**：AppImage 记得 `chmod +x` 后运行，或者直接装 `.deb`

**Android 版**：同样去 [Releases 页面](../../releases) 下载 `.apk`，安装时系统会提示"未知来源"，
允许一下就行。

**iPhone / iPad**：暂时没有现成的安装包，建议直接用[网页版](https://lyrics.response.run/)，
体验跟安装版基本一样。如果你熟悉开发环境，也可以自己拉源码构建 iOS 版。

## 关于数据

歌词内容只存在你自己的设备本地（浏览器或应用的本地存储里），不会传到云端、
也不会经过任何服务器。换设备、换浏览器，或者清了本地数据之前，记得先导出一份
工程文件备份，不然找不回来。
