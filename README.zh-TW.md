名字是「詞格」+「醬」——後者取日語 ちゃん 的親暱後綴。

## 這是做什麼用的

寫中文歌詞的時候，作曲常常會先給一份「詞格」——每句幾個字、哪裡停頓分組，
比如 `2/2/3` 就是「兩個字、兩個字、三個字」這樣一句。詞格醬就是把這種格子
擺出來，讓你對著格子逐字填詞，輸入法直接連打，不用自己數字數、避免超格或漏格。

## 功能

- 按詞格擺格子逐字填詞，點哪個格子就寫在哪個格子
- **格子是釘死的**：打字覆蓋目前這一格，不會把後面的字往後頂；刪字原地留成空格，後面的字也不會往前挪。先寫好的句尾始終待在自己的格子裡，不會被擠出詞格弄丟
- 可以先落句尾那幾個字、前面留空慢慢填
- 句內停頓分組（如 `2/2/3`），加減格只作用於游標所在的分句
- 整句寫偏了可以用 `Alt + ←/→` 左右挪一格，詞格不動；會把字擠出詞格時會攔住
- 每句可以存多個備選寫法，隨時切換比較，切換前會自動保住還沒存的版本
- 每句可以加備註，不佔格子
- 自訂背景：圖片 / 純色 / 兩套底色，遮罩與模糊都能調
- 支援匯入 txt 詞格，或拿現成歌詞反推出詞格；匯出歌詞（分句之間會留出空格，所以匯出的歌詞能被原樣再匯入回來；可選擇是否帶上全部備選寫法與備註）、匯出詞格、匯出專案檔
- **（實驗）日語拗音**：打日語歌詞時，`きゃ` `しゅ` `ちょ` 這類拗音會自動跟前一個假名拼成一格，顯示為主字右下角的小字，不單獨佔格，數格子時按音拍算而不是按字元數；促音 `っ／ッ` 不算在內，仍然獨立佔一格
- **韓語相容**：諺文（如 `한`）本身就是一個完整的 Unicode 字元，天然一格一個音節，不需要像日語拗音那樣額外處理，直接填字即可
- **（實驗）MIDI 匯入／匯出**：按旋律的音符數量自動生成詞格，用三個 keyswitch（C0 分句／C#0 換句／D0 換段）當分段標記。匯入一份沒放 keyswitch 的 MIDI 時會先提示——所有音符會擠進一句，匯入後得自己動手分句分段——確認了才匯入。配套兩種匯出：去掉 keyswitch 的純淨 MIDI，以及帶逐句校驗的歌詞版 MIDI（詞格跟音符數量對不上會直接攔住，不會匯出錯位的歌詞；歌詞版能被 Synthesizer V 等支援 MIDI 歌詞的軟體讀取）
- **介面語言**：中文 / 繁體中文 / 日本語 / 한국어，右上角下拉切換，說明面板等長文說明也會跟著換

## 怎麼用

**網頁版**：打開 [lyrics.response.run](https://lyrics.response.run/) 直接用，電腦、手機瀏覽器都支援，不用裝任何東西。

**電腦安裝版（Windows / macOS / Linux）**：到 [Releases 頁面](../../releases) 下載對應平台的安裝包。
這些包沒有做付費簽章，第一次打開時系統會攔一下，這是正常現象：

- **Windows**：點「更多資訊」→「仍要執行」
- **macOS**：對應用程式按右鍵 →「打開」→ 再點彈出視窗裡的「打開」，只需做一次
- **Linux**：AppImage 記得 `chmod +x` 後再執行，或直接安裝 `.deb`

**Android 版**：一樣到 [Releases 頁面](../../releases) 下載 `.apk`，安裝時系統會提示「不明來源」，
允許一下就行。

**iPhone / iPad**：目前沒有現成的安裝包，建議直接用[網頁版](https://lyrics.response.run/)，
體驗跟安裝版基本一樣。如果你熟悉開發環境，也可以自己拉原始碼建置 iOS 版。

## 關於資料

歌詞內容只存在你自己的裝置本機（瀏覽器或應用程式的本機儲存裡），不會傳到雲端，
也不會經過任何伺服器。換裝置、換瀏覽器，或清掉本機資料之前，記得先匯出一份
專案檔備份，否則就找不回來了。
