이름은 「詞格(가사의 격자)」＋「醬」——뒤쪽은 일본어 ちゃん에서 온 친근한 호칭입니다.

## 무엇을 위한 도구인가

중국어 가사를 쓸 때 작곡가는 보통 먼저 「격자」를 건네줍니다.
한 줄이 몇 글자이고 어디서 끊어지는지에 대한 지정이죠.
예를 들어 `2/2/3`은 「두 글자, 두 글자, 세 글자」로 된 한 줄이라는 뜻입니다.
CigeChan은 그 격자를 그대로 화면에 펼쳐 놓고, 칸을 따라 한 글자씩 쓸 수 있게 해 줍니다.
입력기로 그대로 이어 치면 되고, 직접 글자 수를 셀 필요도, 넘치거나 모자랄 걱정도 없습니다.

## 기능

- 격자대로 칸을 배열해 한 글자씩 입력. 클릭한 칸에 바로 써집니다
- **칸은 고정됩니다**: 글자를 쓰면 커서가 있는 칸을 덮어쓸 뿐 뒤의 글자를 밀어내지 않고, 지워도 그 자리가 빈 칸이 될 뿐 뒤의 글자가 앞으로 당겨지지 않습니다. 먼저 써 둔 줄 끝은 끝까지 제자리를 지키며, 격자 밖으로 밀려나 사라지는 일이 없습니다
- 줄 끝의 몇 글자만 먼저 정해 두고, 앞부분은 비워 둔 채 천천히 채울 수 있습니다
- 줄 안의 소절 구분(`2/2/3` 등)을 지원하며, 칸을 늘리거나 줄이는 조작은 커서가 있는 소절에만 적용됩니다
- 한 줄 전체가 한 칸씩 어긋났을 때는 <kbd>Alt + ←/→</kbd>로 좌우로 옮길 수 있습니다(격자는 그대로. 글자가 밀려나는 경우에는 실행되지 않습니다)
- 한 줄에 여러 대안을 저장해 두고 언제든 전환해서 비교할 수 있습니다. 전환하기 전에 저장하지 않은 표현은 자동으로 저장됩니다
- 줄마다 메모를 남길 수 있습니다(칸을 차지하지 않습니다)
- 배경 사용자 지정: 이미지 / 단색 / 두 가지 바탕색, 마스크 농도와 블러도 조절할 수 있습니다
- txt 격자 가져오기, 또는 이미 완성된 가사에서 격자를 역으로 추론하기를 지원합니다. 가사 내보내기(소절 사이에 공백이 들어가므로 내보낸 가사를 그대로 다시 가져올 수 있고, 모든 대안과 메모를 함께 넣을지도 선택 가능), 격자 내보내기, 프로젝트 파일 내보내기도 됩니다
- **(실험적) 일본어 요음**: 일본어 가사를 입력하면 `きゃ` `しゅ` `ちょ` 같은 요음이 자동으로 앞 가나와 한 칸으로 합쳐지고, 본래 글자의 오른쪽 아래에 작게 표시됩니다. 별도의 칸을 차지하지 않으므로 칸 수가 글자 수가 아니라 음박 수와 맞아떨어집니다. 촉음 `っ／ッ`은 여기 포함되지 않고 여전히 한 칸을 차지합니다
- **한국어 호환**: 한글(`한` 등)은 그 자체로 완결된 하나의 유니코드 문자라 처음부터 한 칸에 한 음절이 대응됩니다. 일본어 요음처럼 별도의 처리가 필요 없고 그냥 입력하면 됩니다
- **(실험적) MIDI 가져오기/내보내기**: 멜로디의 음표 개수로 격자를 자동 생성합니다. 구간 표시에는 keyswitch 세 개(C0 소절 구분／C#0 줄 바꿈／D0 섹션 전환)를 씁니다. keyswitch가 들어 있지 않은 MIDI를 가져오려 하면, 모든 음표가 한 줄에 들어가서 가져온 뒤 직접 소절과 줄을 나누어야 한다는 점을 먼저 확인합니다. 내보내기는 두 가지 — keyswitch를 제거한 클린 MIDI, 그리고 줄 단위 검증을 거친 가사 포함 MIDI(격자와 음표 수가 맞지 않으면 그 자리에서 막아 주므로 어긋난 가사가 나가지 않습니다. 가사 포함 쪽은 Synthesizer V 등 MIDI 가사를 지원하는 프로그램에서 읽을 수 있습니다)
- **인터페이스 언어**: 中文 / 繁體中文 / 日本語 / 한국어. 오른쪽 위 드롭다운에서 전환할 수 있고, 도움말 패널 같은 긴 설명문도 함께 바뀝니다

## 사용 방법

**웹 버전**: [lyrics.response.run](https://lyrics.response.run/) 을 열면 바로 쓸 수 있습니다.
PC와 모바일 브라우저 모두 지원하며 설치할 것이 없습니다.

**데스크톱 버전(Windows / macOS / Linux)**: [Releases 페이지](../../releases)에서 플랫폼에 맞는 설치 파일을 받으세요.
유료 서명을 하지 않아서 처음 열 때 시스템이 한 번 막는데, 정상적인 현상입니다:

- **Windows**: 「추가 정보」 → 「실행」
- **macOS**: 앱을 우클릭 → 「열기」 → 대화상자에서 다시 「열기」. 처음 한 번만 하면 됩니다
- **Linux**: AppImage는 `chmod +x` 후 실행하거나, `.deb`를 그대로 설치하세요

**Android 버전**: 마찬가지로 [Releases 페이지](../../releases)에서 `.apk`를 받으세요.
설치할 때 「출처를 알 수 없는 앱」 안내가 뜨는데 허용해 주면 됩니다.

**iPhone / iPad**: 아직 배포 패키지가 없습니다. [웹 버전](https://lyrics.response.run/)을 그대로 쓰시길 권합니다.
사용감은 설치 버전과 거의 같습니다. 개발 환경에 익숙하다면 소스를 받아 직접 iOS 버전을 빌드할 수도 있습니다.

## 데이터에 대해

가사 내용은 본인 기기의 로컬(브라우저 또는 앱의 로컬 저장소)에만 저장되며,
클라우드로 올라가지도, 어떤 서버를 거치지도 않습니다.
기기나 브라우저를 바꾸기 전에, 또는 로컬 데이터를 지우기 전에 프로젝트 파일을
내보내 백업해 두세요. 그러지 않으면 되돌릴 수 없습니다.

## AI 작사 기능 안내 및 면책 조항

「AI 작사」는 실험적 기능입니다. 사용 전에 다음을 확인해 주세요.

- 이 기능을 사용하려면 **서드파티 LLM API(OpenAI 호환 형식)를 직접 설정**하고 그로 인해 발생하는 모든 비용과 위험을 부담해야 합니다. API의 가용성·안정성·콘텐츠 품질은 사용자가 선택한 제공자의 책임이며 본 도구 및 작성자와 무관합니다
- **词格酱은 설정 정보, API Key, 가사 정보를 수집하지 않습니다.** 이러한 내용은 사용자의 기기(브라우저 또는 앱의 로컬 저장소)에만 저장됩니다. 본 도구에는 서버가 없으며 데이터를 거치지도 않습니다
- 다만 작사 버튼을 누르면 **가사 정보와 요청 내용이 직접 입력한 LLM API로 전송됩니다**(AI 생성을 위해). 해당 제공자를 신뢰할 수 있는지, 개인정보 처리방침도 함께 확인해 주세요
- AI가 생성한 내용은 인공지능이 자동으로 만든 것으로 **창작 참고용**입니다. 직접 판단하고 수정한 뒤 사용하십시오. 저작권 및 콘텐츠 준수에 관한 책임은 사용자에게 있습니다
- 본 기능은 「현재 상태 그대로」 제공되며 명시적이든 묵시적이든 어떠한 보증도 하지 않습니다. **词格酱 제작팀은 「AI 작사」 기능의 오용으로 인한 어떠한 손실에도 책임을 지지 않습니다**

본 기능을 사용하면 위 내용을 읽고 이해한 것으로 간주됩니다.
